# EduTrack - Student Performance Analysis System

A comprehensive platform designed to empower students and educators with real-time performance insights, detailed analytics, and seamless communication tools.

## Features

- **Dashboard Analytics** - Track academic progress with visual charts and statistics
- **Admin Portal** - Manage students, faculty, and institutional data
- **Student Portal** - Access grades, attendance, and assignments
- **Registration System** - Easy onboarding for new students
- **Performance Tracking** - Monitor and analyze student performance trends

## Tech Stack

- HTML5
- CSS3

## Getting Started

1. Clone or download the project
2. Open `index.html` in your browser, or
3. Run a local server:
   ```bash
   python -m http.server 8080
   ```
4. Navigate to `http://localhost:8080`
